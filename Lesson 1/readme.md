# Goal
you will be testing the `calculator.py` file.

you are permitted to look at each function.


| Function | math value   | Constraint            |
| -------- | ------------ | --------------------- |
| multiply | $$a*b$$      | NA                    |
| add      | $$a+b$$      | NA                    |
| subtract | $$a-b$$      | NA                    |
| exponent | $$a^b$$      | NA                    |
| sqrt     | $$\sqrt{a}$$ | must be whole numbers |

Each of these functions has one or more errors. you must reveal them by any of the following methods:
- black box.
- white box.

There are at least 6 Errors within the code that you must find.
Your test cases can either test an array of cases (recommended) or you may isolate specific issues.
> [!NOTE]
> Each function has a minimum of 1 issue. Some are more obvious than others.
